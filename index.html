설정 방법 (한 번만 하면 됩니다)

▼
1. 토큰 만들기 — github.com 로그인 → 우측 상단 프로필 → Settings → 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  이름 아무거나, Expiration은 길게(예: 1년 또는 No expiration), Account permissions → Gists → Read and write. 생성 후 토큰 문자열을 복사.
2. 이 기기 연결 — 위 토큰 칸에 붙여넣고 "연결 / 최초 업로드". 비공개 Gist가 만들어지고 Gist ID가 채워집니다.
3. 다른 기기 — "공유 주소 복사"로 얻은 주소를 열면 Gist ID가 자동 입력됩니다. 토큰만 붙여넣고 "연결"을 누르면 같은 데이터를 봅니다.
4. 이후 — 저장할 때마다 자동 업로드, 페이지를 열 때 자동으로 최신 데이터를 내려받습니다. 양쪽에서 동시에 수정했다면 더 최근 저장본이 우선하며, 덮어쓰기 전 확인을 요청합니다.
